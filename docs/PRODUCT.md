# 产品定义

定位：**极其顺手的 AI 远程工作台**。

在同一个界面管理服务器、文件和终端，随时把当前工作交给 AI，也随时接回来。SSH/SFTP 是第一批基础能力，产品围绕连续操作、上下文交接和可核对的结果设计。

0.2 主入口是 **DSH 原生右侧栏的远程 Agent 模式**：中央保留正常 DSH 会话，右侧只呈现服务器监控与远程文件/文档，不包含终端或独立聊天。监控有综合、CPU、显卡、内存、磁盘、网络；文件支持多标签、Markdown、PDF 批注/表单、代码与媒体预览。模型与审批沿用当前会话。

验收闭环：连接一台服务器 → 浏览目录 → 上传文件 → 在右侧栏编辑 → 保存并检查冲突 → 授权交给当前 DSH 会话 → 查看操作结果；独立工作台另提供终端、Diff 与命令栏。

交互约束：

- 面板内导航只在顶部：主机切换、搜索、连接状态与主要操作由顶栏及其下拉弹层承担，不做常驻左侧主机或导航栏；DSH 原生侧栏只保留标准启动入口。
- Agent 模式通过官方 `sidebarRightTabs` 与 `sidebar.right.pane.tab` 合同嵌入真正的 DSH 右侧栏，支持原生开关与放大；不可用独立主页面中的窄栏替代。
- 视觉与主题跟随 DSH：复用宿主 `--dsw-*` 主题变量、圆角、字体与字号设置，终端调色板同样取自宿主，明暗与“跟随系统”随 DSH 切换；不维护独立配色。
- 主机、账号、环境和目录始终可识别。
- 文件与监控进入 DSH 原生右侧栏，与中央对话并排；独立工作台提供文件与终端同屏，切换面板不结束远端 PTY。
- 文件编辑与异步操作绑定原始主机和连接版本。
- 交给 Agent 的内容发送前可查看、编辑；密码和私钥不进入工具参数，凭据保存在 DSH 凭据记录中。
- 人和 AI 共用连接配置、任务和文件服务，手动终端保留独立输入权。
- 执行结果如实区分完成、失败、取消与未知；未知结果需要核对。
- 常用功能使用真实后端，开发预览明确标识本机测试服务器及 AI 可用范围。

后续优先顺序：目录递归传输与可靠续传 → AI 修改提案与恢复副本 → 终端 tmux 恢复 → 会话上下文更完整的原生融合 → 多协议适配。
