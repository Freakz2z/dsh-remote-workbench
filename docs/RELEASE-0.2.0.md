# 0.2.0 Alpha：DSH 原生右侧远程 Agent

验证日期：2026-11-17。DSH：0.2.2-rc.3；平台：macOS。

## 使用入口

在普通 DSH 会话中，点击标题栏的远程 Agent 按钮；也可以打开 DSH 自带的右侧栏，从引导页或 **+** 菜单选择 **远程 Agent**。中央继续使用原生对话，右侧提供文件与监控，不包含终端、命令栏或第二套聊天。

UI/UX 由 DSH 的 DeepSeek V4.1 Flash 实施。使用宿主的字体、圆角、颜色和明暗主题变量；插件内部采用顶部切换。

## 本次能力

- 综合、CPU、显卡、内存、磁盘和网络六类监控，历史趋势、暂停与刷新间隔。Linux 采用固定只读 SSH 采样；NVIDIA / AMD 取决于硬件、驱动和权限。缺失数据明确显示不可用。
- 远程文件浏览、新建、上传下载、复制、移动、权限修改和删除文件 / 空目录。多文档标签与草稿在切换监控时保留。
- CodeMirror 语法高亮与查找替换；Markdown 源码、预览与分屏；图片及浏览器支持的音视频预览。
- PDF 分页、适应宽度、缩放、文字批注、已有表单填写和页面旋转，保存经 SFTP 原子替换。独立 PDF worker 不覆盖 DSH 自带的 worker 全局。
- 文件与监控摘要可以先预览，再交给当前 DSH 会话。新增 `rw_resources` 工具，只需当前主机读取授权，不要求 Shell 执行授权。
- 从工作台打开文件时回到会话，在原生右侧栏打开；工作台本身不再有 AI 协作栏和内嵌编辑器。
- 密码 / 私钥口令保存到 DSH 凭据记录，输入一次后重连无需重输；可随时“忘记已保存凭据”。
- 新增 `rw_connect`：在已授权主机上使用已保存凭据重连，不接收或返回密码；授权可在首次连接前创建。
- 所有右栏文件操作（含新建、目录、复制、重命名、`chmod`、删除）绑定发起时的连接版本，文本 / PDF 保存同时校验内容 etag。其他窗口修改连接配置后，旧操作会拒绝执行并保留草稿。

独立工作台仍作为次要入口保留原有 SSH 终端与隧道；命令补全、显式发送历史和片段库仅用于该工作台。

## 范围与限制

文本编辑仅支持 1 MiB 内 UTF-8；二进制预览和 PDF 保存上限 25 MiB。其他格式可下载。HTML / SVG 只作为源码处理，Markdown 预览经过清理，外部图片主动点击后加载。

PDF 编辑包括批注、表单与旋转，不包含任意排版修改、OCR、数字签名或嵌入字体替换；中文批注采用栅格图像。

macOS 的 GPU、逐核心与磁盘 I/O 实时指标不可用。Linux NVIDIA / AMD 解析已用确定性数据测试，当前验收机器没有对应 GPU，未进行物理显卡实测。

隔离集成检查不发送外部模型请求；工具探针直接调用已注册的工具定义，不代替完整 DSH 原生工具审批流程测试。未使用用户真实远程服务器或凭据。
