# 用户最新补充：整体跟随 DSH

**整体 UI/UX 与配色都跟随和模仿 DSH。** 这条要求优先于你此前已开始实施的独立视觉方案。

- 工作台应当看起来、用起来像 DSH 原生面板：字体、字号、间距、圆角、边框、背景层级、按钮、输入框、下拉、弹窗、图标、悬停/焦点/选中反馈都尽量与 DSH 一致。
- 优先使用 DSH 现有主题变量和组件契约，查看官方主题与样式文档后使用实际存在的 token。颜色要来自宿主，不要继续沿用旧版插件独立的奶绿色配色。
- 深色、浅色与系统主题随 DSH 切换，正在运行的终端、编辑内容与输入草稿应保持。独立预览可使用贴近 DSH 的回退主题，但不能把回退颜色固定到宿主里。
- 终端、文件、编辑器、AI 区、任务栏、连接弹窗应一起适配，避免只有顶栏像 DSH、其他区域还保留独立皮肤。
- 导航约束保持：插件内部仅顶部导航，不做常驻左侧主机/导航栏；DSH 原生左侧启动按钮保留，不改 DSH 自身侧栏。
- 继续由 Flash 自主设计与实施，直接把此要求合并进正在进行的工作。后端、权限、协议行为和打包契约不变。
- 完成时说明复用的 DSH 风格/主题机制，并检查明暗两种主题以及实际 DSH 中的观感；无法完成的验证如实记录。
